# Champions & Elite Four Rotating Team Configurations Knowledge Base
*Seasonal & Monthly Roster Variants for Gens 1–5 (Level 100 Competitive Sets)*

---

## 1. Executive Summary & Monthly Rotation Architecture

To keep Battle Cynthia fresh, replayable, and competitive across months and seasons, each Champion and Elite Four member requires **multiple distinct team configurations**. 

Instead of fighting the exact same 6 Pokémon every time Cynthia or Blue appears:
- **Monthly / Weekly Rotation**: Each champion possesses **5 unique canonical/competitive team configurations** (Configs A through E) inspired by different game appearances (Original, Rematch, Pokémon World Tournament, Challenge Mode, and Archetype Variants).
- **Format**: All teams are normalized to **Level 100** with authentic Generation 3–5 items (Leftovers, Focus Sash, Choice items, Type-resist berries), abilities, and competitive 4-move distributions.
- **Strategic Variety**: Each configuration shifts the AI's win condition (e.g., Cynthia varying between her classic Platinum mixed balance, a bulky Gastrodon DP stall core, a fast Undella Town B2W2 offensive lineup, or a PWT Dragon/Steel hazard beatdown).

## 4. TypeScript Architectural Model for Monthly Roster Swapping

When ready for code implementation, the game can load and hot-swap these configurations via an indexed catalog:

```typescript
export interface ChampionConfigEntry {
  configId: 'A' | 'B' | 'C' | 'D' | 'E';
  name: string;
  seasonLabel: string;
  theme: string;
  team: Pokemon[];
}

export type ChampionRosterRegistry = Record<
  'cynthia' | 'blue' | 'lance' | 'steven' | 'wallace' | 'iris' | 'alder',
  ChampionConfigEntry[]
>;

/**
 * Retrieves the active Champion configuration based on the current calendar month (1-12)
 * Month 1, 6, 11 -> Config A
 * Month 2, 7, 12 -> Config B
 * Month 3, 8     -> Config C
 * Month 4, 9     -> Config D
 * Month 5, 10    -> Config E
 */
export function getMonthlyChampionConfig(
  championId: keyof ChampionRosterRegistry,
  date: Date = new Date()
): ChampionConfigEntry {
  const configs = CHAMPION_ROSTER_REGISTRY[championId];
  const month = date.getUTCMonth(); // 0 to 11
  const configIndex = month % configs.length;
  return configs[configIndex];
}
```
