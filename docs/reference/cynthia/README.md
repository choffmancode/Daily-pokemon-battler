# Champion Cynthia Reference Assets

These reference assets are saved for the future implementation of Champion Cynthia in Daily Champion (`pokemon-battler`):

1. **`cynthia_battle_intro_dpp.png`**:
   - Canonical Diamond / Pearl / Platinum in-game battle intro stance and trainer pedestal composition against Lucas.
   - Reference for: Full-body black trenchcoat battle sprite, pose, proportions, and Gen 4 battle stage pedestal placement.

2. **`cynthia_tcg_supporter.png`**:
   - Official Cynthia TCG Supporter Card (Ultra Prism / Hidden Fates).
   - Reference for: Expressive battle portrait art, pointing hand pose, and dynamic high-resolution presentation.

3. **`cynthia_official_bust.png`**:
   - Official Ken Sugimori / anime character bust artwork.
   - Reference for: Dialogue box portrait crops, hair ornaments, hair shading, and facial expression.
